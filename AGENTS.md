# Инструкции для агентов

## Стилевые переменные и токены

Перед добавлением переменной или токена стилей в UI-пакете агент сначала изучает уже существующие определения. Если есть переменная, подходящая по смыслу, нужно использовать её вместо создания дубликата. Если подходящей переменной нет, агент предлагает новую по принятой системе именования и объясняет, зачем она нужна.
